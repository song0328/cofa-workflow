# 사내 교육 세션 배정

인재개발팀은 11월 셋째 주(11/16~11/20)에 사내 교육을 엽니다. 지금은 직원을 엑셀에서 손으로 세션에 넣고 있어서 정원 초과, 시간 겹침, 필수 과목 누락이 자주 생깁니다.

제공 자료로 직원을 교육 세션에 배정하는 기능과, 그 결과를 쓰는 작은 웹 서비스를 만들어 주세요.

## 제공 자료 (`data/`)
- `employees.csv` — 직원 목록
- `courses.csv` — 과목 (`mandatory_roles`: 필수로 들어야 하는 직무)
- `sessions.csv` — 이번 주 세션
- `preferences.csv` — 선택 과목 희망
- `changed/sessions_v2.csv` — 운영자가 다음에 올릴 세션 변경 파일(검증용)

## 요청
1. 배정은 세션 정원과 개인 시간 겹침을 지켜야 합니다. 필수 과목과 희망은 최대한 반영해 주세요.
2. 교육 운영자는 세션 정보를 고치고 다시 배정할 수 있어야 합니다.
3. 직원은 자기 배정 결과를 볼 수 있어야 합니다.
4. 세션 변경 파일을 올릴 수 있어야 하고, 잘못된 내용은 걸러야 합니다.
5. 가능하면 Docker로 실행할 수 있게 해 주세요.

## 제출물
- 소스 코드와 실행·검사 방법(README)
- `DECISIONS.md` — 주요 결정과 근거, 가정
- `AI_COLLABORATION.md` — AI와 협업한 방식과 판단 기록

세부 기준은 인재개발팀 교육 운영 담당자에게 문의하세요.
