# 모의 확인 문제 — 교육 세션 배정 (연습이 **끝난 뒤** 연다)

AI·코드·문서를 닫고, 문항마다 5분 타이머로 1~3문단을 직접 쓴다. 답 틀: **결정·이유 → 약점 → 파급 → 다음 검증**, 실제 숫자 하나 이상.
먼저 `python3 <키트>/tools/predict_questions.py .`로 내 제출물에서 나온 질문을 보고, 아래 8문항으로 보충한다.

| # | 칸 | 질문 | 좋은 답에 들어갈 것 |
|---|---|---|---|
| 1 | 1 방법 선택 | 필수 과목 배정에 어떤 방법을 썼나? 사번 순서대로 넣는 단순 방법과 비교해 무엇이 나아졌는지 숫자로, 그리고 감수한 한계는? | 기준선 vs 개선 같은 지표(필수 미배정·희망 1순위 반영 수), 위반 0, 최적 증명은 없음 |
| 2 | 5 변화·판단 | 기술직 필수 9시간과 주 8시간 상한이 부딪쳤을 때 어느 과목을 이월하자고 제안했고 왜인가? 다른 과목을 이월했다면 결과가 어떻게 달라지나? | 담당자 답(상한 우선) 원문, 제안과 승인, 이월 인원 수, 좌석 여유 변화 |
| 3 | 2 구조·흐름 | 운영자가 S07 정원을 고치고 재배정을 누르면 어떤 파일(모듈)을 거쳐 직원 화면에 반영되나? 확정 결과는 어디에 저장되고 누가 바꾸나? | 입력 검증 → 계산 → 확정 저장 → 조회, 파일 이름, 확정본·작업본 구분 |
| 4 | 2 구조·권한 | 직원이 다른 직원의 배정을 볼 수 없게 막은 곳은 어디인가? 화면에서 숨긴 것과 서버에서 막은 것을 나누면? | 서버에서 세션의 사번으로 거르기, 다른 사번 요청 시 응답 코드, 확인한 검사 이름 |
| 5 | 3 구현 vs 가정 | S04 정원 빈칸과 직무 빈칸 3명을 어떻게 처리했나? 담당자가 정한 것과 내가 가정한 것을 나누고, 평가자가 확인할 경로는? | 출처 구분(담당자 답 / 가정), 테스트 이름, 화면의 '확인 필요' 목록 |
| 6 | 4 장애·운영 | `sessions_v2.csv`를 올리면 무슨 일이 일어나나? 틀린 행이 섞였거나, 두 운영자가 동시에 저장하면? | 파일 전체 거절 + 행별 사유, 기존 배정 유지, 버전 비교로 늦은 저장 거절 |
| 7 | 6 AI 협업 | AI가 처음 만든 코드에서 조용히 가정한 것(예: 빈칸을 0으로, `active`를 비재직으로, 자정 넘김 계산)을 어떻게 발견했고, 받아들이고·고치고·버린 것은? | `AI_COLLABORATION.md`의 실제 행, 계기(검사 실패·원자료 대조), 증거 명령 |
| 8 | 3 구현 vs 가정 · **전제 틀림** | S04를 0석으로 보고 C01 배정이 불가능하다고 판정한 이유는? | 첫 문장으로 전제를 바로잡는다: "질문은 0석을 전제했지만 실제로는 담당자 답대로 24석으로 처리했고…"(내가 실제로 한 것에 맞춰) |

## 다 쓴 뒤
- 내 답을 제출 파일과 대조한다. 틀린 사실 → 노트에, 문서와 코드가 어긋난 곳 → 실제 시험이었다면 제출 전에 고쳐야 했던 곳.
