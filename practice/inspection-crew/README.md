# 설비 점검 작업 배정

설비보전팀은 11/23~11/25 사흘 동안의 설비 점검 작업을 기사들에게 나눠야 합니다. 지금은 아침마다 화이트보드와 메신저로 나누다 보니 마감을 놓치거나 자격이 없는 기사가 배정되는 일이 생깁니다.

제공 자료로 점검 작업을 기사에게 배정하고 시간 순서를 정하는 기능과, 그 결과를 쓰는 작은 웹 서비스를 만들어 주세요.

## 제공 자료 (`data/`)
- `technicians.csv` — 기사 목록(자격, 근무 시간)
- `equipment.csv` — 설비 목록
- `tasks.csv` — 점검 작업(필요 자격, 작업 시간, 우선순위, 마감)
- `leave.csv` — 휴가
- `changed/tasks_v2.csv` — 관리자가 다음에 올릴 작업 변경 파일(검증용)

## 요청
1. 기사의 자격과 근무 시간을 지키면서 작업을 배정하고, 기사별 작업 순서와 시각을 정해 주세요. 마감은 최대한 지켜야 합니다.
2. 정비 관리자는 작업을 고치거나 추가하고 다시 계산할 수 있어야 합니다.
3. 기사는 자기 일정을 볼 수 있어야 합니다.
4. 작업 변경 파일을 올릴 수 있어야 하고, 잘못된 내용은 걸러야 합니다.
5. 가능하면 Docker로 실행할 수 있게 해 주세요.

## 제출물
- 소스 코드와 실행·검사 방법(README)
- `DECISIONS.md` — 주요 결정과 근거, 가정
- `AI_COLLABORATION.md` — AI와 협업한 방식과 판단 기록

세부 기준은 설비보전팀 담당자에게 문의하세요.
