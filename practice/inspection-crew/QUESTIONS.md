# 모의 확인 문제 — 설비 점검 작업 배정 (연습이 **끝난 뒤** 연다)

AI·코드·문서를 닫고, 문항마다 5분 타이머로 1~3문단을 직접 쓴다. 답 틀: **결정·이유 → 약점 → 파급 → 다음 검증**, 실제 숫자 하나 이상.
먼저 `python3 <키트>/tools/predict_questions.py .`로 내 제출물에서 나온 질문을 보고, 아래 8문항으로 보충한다.

| # | 칸 | 질문 | 좋은 답에 들어갈 것 |
|---|---|---|---|
| 1 | 1 방법 선택 | 2인 1조 프레스 점검이 있는 배정·순서 문제에 어떤 방법을 썼나? 마감 빠른 순 단순 배정(기준선)과 비교한 숫자와, 감수한 한계는? | 기준선 vs 개선 같은 지표(P1 준수 수·미배정·P2 지연 합계), 위반 0, 2인 작업을 다룬 방식 |
| 2 | 5 변화·판단 | 11/24 연장 2시간 허용이 결과를 어떻게 바꿨나? 연장을 줄이는 것과 P2 지연을 줄이는 것은 어떤 트레이드오프였나? | 프레스 P1 연장 없이 n/10 → 연장 후 n/10, 총 연장 시간, 담당자 답 원문 |
| 3 | 2 구조·흐름 | 관리자가 긴급 작업 하나를 추가하고 재계산하면 데이터가 어떤 파일(모듈)을 거치고, 결과는 어디에 저장되나? | 입력 검증 → 계산 → 검사기 → 확정 저장 → 기사 조회, 파일 이름, 버전 |
| 4 | 2 구조·권한 | 기사 화면에서 다른 기사 일정이 보이지 않게 막은 곳은? 2인 1조 짝 정보는 어디까지 보여 주나? | 서버에서 기사 번호로 거르기, 짝 번호만 노출, 다른 번호 요청 시 응답 코드와 검사 이름 |
| 5 | 3 구현 vs 가정 | 다음 날 06:00 마감 작업과 야간조 날짜 귀속을 어떻게 처리했나? 구현·검증한 것과 가정으로 둔 것, 확인 경로는? | 담당자 답(시작일 기준), 경계 테스트 이름(06:00 정각 끝 = 준수), 미검증 항목 |
| 6 | 4 장애·운영 | `tasks_v2.csv`를 올리면 어떤 행이 반영되고 어떤 행이 빠지나? 반영 중 계산이 실패하거나 두 관리자가 동시에 저장하면? | 틀린 4행만 거절 + 사유, 나머지 반영, 직전 확정 일정 유지, 늦은 저장 거절 |
| 7 | 6 AI 협업 | AI가 대소문자(`press`·`p1`·`on`)나 빈칸(작업 시간·자격)을 조용히 처리한 곳을 어떻게 발견했고, 무엇을 받아들이고·고치고·버렸나? | `AI_COLLABORATION.md`의 실제 행, 계기(자료 진단·검사 실패), 고친 뒤 바뀐 숫자 |
| 8 | 1 방법 선택 · **전제 틀림** | 프레스 점검을 1인 작업으로 보고 PRESS 기사 4명에게 고르게 나눈 이유는? | 첫 문장으로 전제를 바로잡는다: "질문은 1인 작업을 전제했지만 실제로는 담당자 답대로 2인 1조로…"(내가 실제로 한 것에 맞춰) |
