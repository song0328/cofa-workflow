# AI가 사용자에게 먼저 건넬 한 줄 조언

키트를 쓰는 AI는 아래 시점마다 **해당 줄을 사용자에게 한 줄로** 알려 준다. 길게 설명하지 않는다. 이미 했으면 생략한다.

| 시점 | 사용자에게 건넬 말 |
|---|---|
| 시작 직후 | "왼쪽 SaaS 아이콘(네모 4개)을 한 번 눌러 배정된 업무 도구가 있는지 봐 주세요. 있으면 내용을 요약해 알려 주세요." |
| 분석을 시작할 때 | "README가 언어별로 여러 개면 둘 다 볼게요. 다르면 함정으로 표시합니다. 자원 상한·반드시 지킬 조건·평가 지표 표부터 만들게요." |
| 담당자 질문 목록을 냈을 때 | "맨 위 하나만 보내 주세요. 답이 오면 다음 질문을 드릴게요. 기다리는 동안 읽기·검사 실행은 계속합니다." |
| 담당자가 "기준이 없다"고 답했을 때 | "기준이 없대요. A/B 중 하나를 이유와 함께 골라 주세요. 그 이유가 확인 문제 답이 됩니다." |
| 사양(AGENTS.md)을 만들 때 | "담당자 답이 아닌 것은 가정 칸에 넣었어요. 고칠 게 있으면 지금 말해 주세요." |
| 계획이 섰을 때(계산·배정 과제) | "방법 수준 A/B/C 중 하나를 이유와 함께 골라 주세요. 그리고 담당자에게 기준 2~3안을 숫자로 보여 고르게 할게요(2차 왕복)." |
| AI 제안을 고치거나 버렸을 때 | "AI_COLLABORATION.md에 한 행 남겼어요. 시험에서 이 사례를 그대로 물을 수 있어요." |
| 사람이 에디터에서 파일을 고쳤다고 할 때 | "Ctrl+S로 저장했는지 탭의 저장 표시를 확인해 주세요." |
| 서버를 띄웠을 때 | "Browser에 포트를 넣고 정상·경계·오류 입력 하나씩 직접 눌러 보세요: (입력과 기대 결과 3줄)" |
| 권한 승인 요청이 필요할 때 | "승인 창이 뜹니다. 명령을 읽고 승인해 주세요." |
| 단계가 끝날 때 | "방금 만든 것 3줄과 확인 질문 하나예요. 한 줄로 답해 주세요(`넘어가`도 돼요)." |
| 첫 완주(약 90분) | "필수 흐름이 끝까지 한 번 돌았어요. 여기서부터 개선·검증입니다. 커밋해 둘게요." |
| 120분쯤 | "남은 필수 n개예요. 선택조건은 버릴지 정해 주세요." |
| 필수조건이 일찍 끝났을 때 | "선택조건 전에 `노트 보여 줘`로 확인문제 노트를 한 번 읽어 두세요." |
| 기능 동결(약 150분) · 제출 40~50분 전 | "새 기능은 멈추고 대조(④) → 보고(⑤) → 모의 확인 문제(⑥) → 제출물 정리(⑦) 순서로 갈게요. `모의 확인 문제 해줘`라고 보내 주세요." |
| 제출 직전 | "저장 안 된 파일이 없는지, 제출 문서를 직접 읽었는지 확인해 주세요. `노트 보여 줘`로 「외울 것」을 두 번 읽으세요. 제출하면 수정할 수 없습니다." |
| 제출 직후 | "확인 문제는 AI·키트 없이 직접 씁니다. 이름표(방식/이유/대안/포기/확인)부터 치고 채우세요. 시간이 끝나면 자동 확정됩니다." |
