# AI가 사용자에게 먼저 건넬 한 줄 조언

키트를 쓰는 AI는 아래 시점마다 **해당 줄을 사용자에게 한 줄로** 알려 준다. 길게 설명하지 않는다. 이미 했으면 생략한다.

| 시점 | 사용자에게 건넬 말 |
|---|---|
| 분석을 시작할 때 | "README가 언어별로 여러 개면 둘 다 볼게요. 다르면 함정으로 표시합니다." |
| 담당자 질문 목록을 냈을 때 | "한 메시지에 하나씩 보내 주세요. 답을 기다리는 동안 다음 분석을 진행해도 됩니다." |
| 사양(AGENTS.md)을 만들 때 | "담당자 답이 아닌 것은 가정 칸에 넣었어요. 고칠 게 있으면 지금 말해 주세요." |
| 사람이 에디터에서 파일을 고쳤다고 할 때 | "Ctrl+S로 저장했는지 탭의 저장 표시를 확인해 주세요." |
| 서버를 띄웠을 때 | "Browser에 포트를 넣고 정상·경계·오류 입력 하나씩 직접 눌러 보세요: (입력과 기대 결과 3줄)" |
| 권한 승인 요청이 필요할 때 | "승인 창이 뜹니다. 명령을 읽고 승인해 주세요." |
| 단계가 끝날 때 | "이 단계의 결정 한 줄을 기록했어요. 확인 문제에서 설명할 재료입니다." |
| 120분쯤 | "남은 필수 n개예요. 선택조건은 버릴지 정해 주세요." |
| 제출 30분 전 | "새 기능은 멈추고 대조(④) → 보고(⑤) → 요약(⑥) 순서로 갈게요." |
| 제출 직전 | "저장 안 된 파일이 없는지, 제출 문서를 직접 읽었는지 확인해 주세요. 제출하면 수정할 수 없습니다." |
| 제출 직후 | "확인 문제는 AI·키트 없이 직접 씁니다. 시간이 끝나면 자동 확정되니 짧게라도 먼저 쓰세요." |
