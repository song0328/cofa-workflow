# 시험 화면에서 알아 둘 것 (웹 IDE 플랫폼)

공개 안내와 사전 점검에서 확인한 일반적인 화면 동작이다. 실제 화면·안내가 다르면 화면이 우선한다.

## 저장과 제출
- AI가 터미널에서 고친 파일은 바로 디스크에 써진다. **사람이 에디터에서 고친 파일은 Ctrl+S로 저장**한다. 저장되지 않은 수정은 보존이 보장되지 않는다.
- 에디터 탭·상단의 저장 표시(`저장됨` / `저장 안 됨`)를 본다. AI와 사람이 같은 파일을 동시에 고치면 저장 충돌이 날 수 있다 → 양쪽 내용을 보고 고른다.
- **`제출하고 문제풀기`를 누르면 작업 내용이 제출물로 고정**되고 확인 문제가 이어진다. 누르기 전에: 저장 안 된 파일 없음 · 제출 문서 작성 · 검사 재실행 · 핵심 파일 직접 읽기.

## 화면 구성
- 위: 과제명 · 감독 연결 · CPU/RAM · 남은 시간 · 문제 신고 · 제출하고 문제풀기
- 왼쪽 아이콘: 파일 탐색기 · 검색 · 브라우저 미리보기 · **SaaS(네모 4개)** · MCP
- **SaaS 화면**: 과제에 배정된 업무용 서비스(업무 포털·사내 시스템·시트 등)가 가운데 영역에 열린다. 배정이 없으면 "할당된 SaaS가 없습니다"가 뜬다. **시작할 때 한 번 눌러 본다.** 내용이 있으면 README와 같은 과제 자료로 다룬다. 그 안의 승인·발송·결제 같은 실제 동작 버튼은 담당자 확인 없이 누르지 않는다(권한 밖 행동)
- 가운데: 에디터 + 터미널(`+`로 새 탭) / 오른쪽: 메신저(DMs) — 화면 도우미와 업무 담당자
- 단축키: 저장 Ctrl+S · 탐색기 접기 Ctrl+B · 내용 검색 Ctrl+Shift+F · 파일명 검색 Ctrl+P · 터미널 붙여넣기 Ctrl+Shift+V · 선택 없이 Ctrl+C = 실행 중단

## 알아 둘 동작
- 에디터의 HTML 미리보기(눈 아이콘)는 **그 파일 하나만** 보여 줄 수 있다. 다른 `.js`(데이터·로직)를 못 불러와 선택 칸·목록이 비어 보이면 코드 오류가 아니다 → 서버 + Browser 미리보기로 확인한다.
- **미리보기는 서버를 띄운 뒤에만** 열린다. 실제 포트·경로를 넣는다. 안 되면 원격 데스크톱의 브라우저가 대안일 수 있다.
- **메신저 답을 기다리는 동안에도 작업 공간을 쓸 수 있다.** 담당자 답을 기다리며 AI 작업을 병렬로 진행한다.
- 과제 폴더에 `README.md`와 `README.en.md`처럼 **언어별 README가 함께** 있을 수 있다. 둘 다 훑고, 내용이 다르면 함정으로 기록한다.
- 홈 폴더에 숨김 파일·`uploads/` 같은 환경 파일이 섞여 있다. 과제 파일만 다룬다.
- **브라우저 권한 창(예: 클립보드)이 뜨면 전체화면 이탈로 기록될 수 있다.** 침착하게 바로 처리하고 전체화면으로 돌아간다.
- 전체화면 유지, 다른 창·탭 이동 금지. 플랫폼 오류는 `문제 신고`로 시각·증상 접수.

## 확인 문제(제출 후)
- 문제마다 시간이 따로 시작되고, **시간이 끝나면 쓰던 답이 자동 확정**된다. 빈칸으로 두지 않는다.
- 이전 문제로 돌아갈 수 없고, 복사·붙여넣기를 쓸 수 없다. 키트·AI도 쓰지 않는다.
- 대비는 `playbooks/followup-prep.md`.
