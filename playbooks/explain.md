# 내 결정을 설명할 수 있게 정리하기

평가는 결과물만이 아니라 **내가 결과물을 이해하는지**도 본다. 작업 중에 아래 틀로 정리해 두고, 핵심 파일을 직접 읽는다.

**설명의 기본 틀: 무엇을 선택했나 → 왜 → 무엇으로 확인했나 → 남은 것**

| 묻는 것 | 답의 모양 |
|---|---|
| 목표와 완료 기준 | 목표 한 문장 → 이 부분이 담당자 확인인지 내 가정인지 → 완료 기준과 확인 방법 → 남은 가정 |
| AI에 맡긴 일과 내가 한 일 | 맡긴 것 → 내가 한 것(질문·검증, 실제 입력값) → 왜 따로 검증했나 → 아쉬운 점 |
| 이 코드·검사가 하는 일 | 역할 → 정상·경계·예외 → 내가 직접 본 것 → 못 본 것 |
| 정책이 바뀌면 | 고칠 코드 위치와 값 → 고칠 테스트 값 → 고칠 문서 |
| 어디까지 확인했나 | 확인 범위 → 못 본 것 → 끝낸 근거(요건 번호) → 인계할 것 |
| 가정에 대해 | 가정임을 먼저 → 생길 문제 → 왜 안 물었나 → 무엇을 물으면 끝나나 |

- 하지 않은 확인·받지 않은 담당자 답·AI가 추측한 정책을 사실처럼 말하지 않는다.
- 제출 뒤 확인 문제는 사람이 직접 답한다. 이 키트와 AI를 쓰지 않는다.
