# AI 기능이 들어간 과제 (요약·분류·추천·챗봇)

**먼저 볼 것**: 과제 환경에서 외부 AI API를 실제로 호출할 수 있는지(키 제공 여부). **개인 API 키를 넣지 않는다.** 키가 없으면 모의 응답(고정 규칙·사전)으로 구조를 만들고 그 사실을 문서에 적는다.

**담당자에게 물을 숨은 규칙 예**
- 결과가 틀렸을 때 사람이 확인하는 단계가 있나요?
- 분류 항목 목록이 정해져 있나요? 어느 것에도 안 맞으면?
- 개인정보·민감 정보가 입력에 들어올 수 있나요?
- 응답 형식(JSON 키 등)이 정해져 있나요?

**흔한 함정**: 분류 항목에 "기타/모름" 칸이 없어 가장 가까운 오답을 고름, 응답 형식 검사 없음, AI 출력을 그대로 실행·발송, 평가 데이터 없이 "잘 된다"고 주장.

**원칙**: AI 호출부와 규칙·검증부를 분리. 출력은 스키마로 검사하고 실패하면 안전한 기본값. 정답이 있는 작은 평가 세트(5~10건)로 맞은 수를 센다.

**검증**: 평가 세트 결과표(입력·기대·실제), 형식 오류 입력, 빈 입력, 범위 밖 입력.

**결과물 모양**: 무엇을 AI에 맡기고 무엇을 규칙으로 막았나, 평가 결과, 한계.
