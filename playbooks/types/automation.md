# 자동화 스크립트 (변환·배치·정리·알림)

**먼저 볼 것**: 입력 파일 위치·형식, 출력 위치·형식, 실행 방법(한 번/반복), 실패 시 기대 동작.

**담당자에게 물을 숨은 규칙 예**
- 같은 입력으로 두 번 실행하면 결과가 중복되면 안 되나요?
- 중간에 실패하면 이미 처리한 것은 어떻게 하나요?
- 형식이 깨진 행은 건너뛰나요, 전체를 멈추나요?
- 실제 발송(메일·메신저)은 하나요, 미리보기 파일만 만드나요?

**흔한 함정**: 두 번 실행 시 중복(멱등성), 반쯤 처리된 상태로 멈춤, 원본 파일 덮어쓰기, 실제 외부 발송, 경로 하드코딩, 큰 파일을 한 번에 메모리에 올림(메모리 작음).

**원칙**: 원본은 읽기만, 결과는 새 파일. 처리 건수·건너뛴 건수·실패 건수를 마지막에 출력. 외부 동작은 "보낼 내용 파일"까지만.

**검증**: 정상 입력 / 깨진 행 포함 입력 / 빈 입력 / 두 번 실행 — 각각 출력과 건수 비교(`tools/compare_json.py`).

**결과물 모양**: 실행 명령 한 줄, 입력→출력 예, 처리·실패 규칙, 건수 요약.
