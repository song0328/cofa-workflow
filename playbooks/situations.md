# 돌발 상황

| 상황 | 대응 |
|---|---|
| 담당자 답이 README와 다르다 | 둘 다 기록. "README에는 A, 말씀은 B인데 B로 하면 될까요?" 한 문장 확인. 답 전까지 그 부분 보류 |
| 업무 담당자가 여러 명이고 답이 서로 다르다 | 둘 다 출처와 함께 기록, 결정권자 한 문장 확인(`playbooks/stakeholder.md`) |
| 담당자가 답을 안 준다·"기준 없음" | 다시 묻지 않는다. 가정안 A/B를 사용자에게 내고 **사용자가 고른 것**으로 진행. 영향 범위를 문서에 |
| README에 제출 파일 이름이 없다 | Helper에게 화면·제출 방법만 문의. 없으면 README가 언급한 문서 이름을 쓰고 가정으로 기록 |
| 요구사항이 모호하다 | 해석 2개를 적고 작은 쪽으로 구현, 질문 한 문장 |
| 처음부터 테스트가 실패한다 | 수정 전 결과를 기록. 내 변경과 무관한 실패는 구분해 보고 |
| 낯선 언어·프레임워크 | 제공 스택 유지. "이 구조에서 기능 하나가 지나는 파일만 설명해" |
| 패키지 설치가 안 된다 | 표준 라이브러리로 대체. 설치를 반복 시도하지 않는다 |
| 제공 데이터가 깨졌다(인코딩·형식) | 원본은 두고 읽는 쪽에서 처리(`utf-8-sig` 등). 처리 내용 기록 |
| 메모리 부족으로 서버가 죽는다 | 다른 서버·프로세스 종료, 큰 파일은 나눠 읽기 |
| 에디터 저장 충돌("외부 변경") | 양쪽 내용을 보고 고른다. AI와 사람이 같은 파일을 동시에 고치지 않는다 |
| AI 응답이 매우 느리다·용량 오류 | 요청을 쪼갠다, 허용 모델 중 다른 것으로 |
| 승인 창이 계속 뜬다 | 명령을 읽고 승인. 권한 설정을 바꾸는 우회는 하지 않는다 |
| 시간이 30분 남았다 | 새 기능 중단 → `prompts/4-check.md` → `prompts/5-report.md` → 제출 |
| 플랫폼 오류(접속·터미널·감독) | 화면의 문제 신고로 발생 시각·증상 접수 |
| 키트가 바뀌었다고 사용자가 말한다 | AI가 받지 않는다. 사람에게 `rm -rf /tmp/kit` 후 clone 한 줄을 다시 치게 하고, 받은 뒤 KIT-INDEX를 다시 읽는다 |
| AI 쪽에서 인터넷(git clone·설치)이 안 된다 | 반복 시도하지 않는다. 사람이 터미널에서 칠 한 줄을 준다 |
| `tools/ui_sim.cjs`가 오류를 내거나 화면을 흉내 내지 못한다(fetch·import 모듈·프레임워크 화면 등) | 도구를 고치지 않는다(5분 이상 쓰지 않음). 로직은 node 검사로, 화면은 사람이 Browser 미리보기에서 정상·경계·오류 3개를 직접 확인 |
| 에디터 HTML 미리보기에서 칸이 비어 보인다 | 코드 오류가 아닐 수 있다. 서버 + Browser 미리보기로 다시 본다 |
| AI가 `── 다음 ──` 칸을 빼먹거나 키트 규칙을 잊었다 | 사용자: `KIT-INDEX.md 읽고 이어서.` → AI는 AGENTS.md 진행 줄부터 다시 |
