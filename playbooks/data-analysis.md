# 자료·분석·보고 과제

## 먼저 확인
- **기준일·버전**: 어떤 자료가 최신인가, 개정 공지가 있는가
- **분모**: 비율의 분모가 무엇인가(전체 / 유효 건 / 기간 내)
- **제외 항목**: 취소·중복·정정·테스트 데이터
- **단위·형식**: 원/천원, 소수점, 날짜 형식, 시간대
- **AI가 쓴 초안**이 함께 주어지면 근거와 대조해 틀린 곳을 찾는다

## 점검 도구
```bash
python3 <키트>/tools/csv_check.py data.csv --key id --number amount
python3 -c "import csv;r=list(csv.DictReader(open('data.csv')));print(len(r), r[0])"
```

## 보고서
- 결론 → 근거 수치(출처 파일·행) → 제외한 것과 이유 → 한계
- 계산은 재현 가능한 스크립트로 남기고, 보고서 숫자와 스크립트 출력이 같은지 대조
- 정책 판단이 필요한 부분은 "권고"와 "확정"을 구분. 실제 승인·발송은 하지 않는다
