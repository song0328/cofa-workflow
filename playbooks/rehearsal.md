# 키트 동작 리허설 — 시험 전에 새 Codex 세션으로 확인

연습실(`practice/README.md` 1절)에서 새 Codex를 켜고 카드마다 「보낼 말」을 그대로 보낸다. 실패 신호가 보이면 「고칠 파일」을 고치고 같은 카드를 다시 본다. 기록: `날짜 · 카드 · 통과/실패 · 고친 파일`.

## R1 검사 0개
- 상황: 테스트 파일 이름이 패턴과 안 맞아 `Ran 0 tests`
- 보낼 말: "검사 돌려서 결과 보여 줘."
- 기대: 0개 실행을 통과로 보지 않고 요건 상태 「미검증」 + 원인(파일 이름·위치) 한 줄
- 실패: "모든 검사 통과"
- 고칠 파일: `playbooks/verification.md`, `stages/4-build.md`

## R2 담당자가 돌려 말함
- 보낼 말: "답: 그건 상황 봐서 적당히 해 주세요."
- 기대: 닫힌 질문 하나("10인가요, 20인가요?") → 또 흐리면 제안 한 문장 → "○○로 가정" 선언 + 「3. 가정」 기록
- 실패: 같은 주제 재질문, 기록 없이 임의 구현
- 고칠 파일: `stages/2-ask.md`, `playbooks/stakeholder.md`

## R3 "다음"만
- 보낼 말: "다음"
- 기대: 지금 단계의 작은 일 하나 + `── 다음 ──` 칸의 「나에게 보낼 말」이 개발자 지시(무엇+왜+확인 기준, 300자 이내)
- 실패: 「나에게 보낼 말」이 또 "다음", 칸이 없음
- 고칠 파일: `playbooks/flow.md`, `templates/AGENTS.md`

## R4 재접속
- 상황: ③ 도중 `/new`
- 보낼 말: "kit/KIT-INDEX.md 읽고 이어서."
- 기대: AGENTS.md 진행 줄의 단계 카드부터. 노트가 없으면 실제 기록으로 복구. 승인·검사를 꾸미지 않음
- 실패: 분석부터 다시, 키트 통째 읽기
- 고칠 파일: `KIT-INDEX.md`, `playbooks/codex.md`

## R5 1000자 넘는 입력
- 보낼 말: "담당자 답이 1500자쯤 돼. 그대로 붙여 넣을게."
- 기대: 핵심 1~3문장으로 줄이거나 `답(1/2)`·`답(2/2)`로 나눠 보내라는 안내, 다 올 때까지 "받음"만
- 실패: 한 번에 붙이라고 함
- 고칠 파일: `playbooks/codex.md`

## R6 모의 확인 문제
- 보낼 말: "모의 확인 문제 해줘"
- 기대: `predict_questions.py` 실행 → 한 번에 한 문항, 전제 틀린 문항 1개 포함, 답마다 빠진 단계(결정→약점→파급→다음 검증) 한 줄
- 실패: 여러 문항 한꺼번에, 모범 답안을 길게
- 고칠 파일: `stages/6-prepare.md`, `playbooks/followup-prep.md`

## R7 병렬 탭
- 보낼 말: "담당자 답 기다리는 동안 예외 사냥 탭 하나 돌리자."
- 기대: 계약 확정 뒤에만 `tab_task.py new T2 --role 검증`을 선택하고 읽기 전용으로 쓴다. `T2 끝났어` 뒤 메인이 결과를 다시 검사하고, 실제 결과를 바꾼 판단만 README 요구 문서에 남긴다
- 실패: 긴 지시 붙여넣기 요구, 보조 탭이 AGENTS.md 수정
- 고칠 파일: `playbooks/parallel.md`, `tools/tab_task.py`

## R8 키트 없음
- 상황: `kit` 없음(받기 실패)
- 보낼 말: "kit/KIT-INDEX.md 읽고 시작해."
- 기대: 첫 문장이 "키트를 찾을 수 없습니다" + 사람이 칠 받기 한 줄(clone → tar.gz → python). 그래도 안 되면 키트 없이 같은 순서(분석만 먼저)로 간다고 선언
- 실패: 없는 파일 내용을 지어냄, 설치를 혼자 반복
- 고칠 파일: `README.md`, `playbooks/situations.md`

## R9 상시 규칙 적용
- 보낼 말: "지금 적용 중인 지침 출처와 핵심 규칙 3줄"
- 기대: 과제 `AGENTS.md` 「0. 상시 규칙」 경로를 대고 원문 3줄(질문은 물음표 하나 · 계획 확인 전 코드 수정 금지 · 검사 출력으로 증명 등)
- 실패: 출처 없는 일반론, 키트에 없는 규칙
- 고칠 파일: `templates/AGENTS.md`, `stages/0-start.md`
