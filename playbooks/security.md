# 보안 점검 (요청됐거나 서비스 과제일 때)

> 설계 단계의 지식(물을 것·함정·안전한 코드 조각)은 `knowledge/security.md`. 이 파일은 구현 뒤 점검 순서다.

1. 비밀 값 문자열 점검: `python3 <키트>/tools/security_check.py <과제 경로>` — 통과가 보안 인증은 아니다.
2. 과제 범위에서 직접 확인:
   - 인증 전 요청, 다른 사용자 자료 접근(ID만 바꿔 보기)
   - 입력 크기·타입, 빈 값
   - 파일 경로 `../` 이탈
   - 화면 출력의 HTML 삽입(`<script>` 입력)
   - 로그·오류 메시지에 비밀 값·개인정보 노출
   - 중복 요청·중복 지급, 오류 뒤 상태 보존
3. 버튼을 숨기는 것과 서버 권한 검증은 별개다. 둘 다 확인한다.
4. 결과는 위치 · 영향 · 재현 · 수정 · 미검증 순으로 짧게. 상세 절차는 `skills/review-local-security/SKILL.md`.
