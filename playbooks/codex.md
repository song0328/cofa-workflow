# Codex 운용 카드 — 모델·승인·끊김·토큰

시험 환경의 Codex CLI를 쓸 때의 요령이다. 화면 안내·운영 메일이 다르면 그쪽이 우선이다. 모르는 기능은 시험 중에 실험하지 않는다.

## 모델과 생각 강도
| 상황 | 설정 |
|---|---|
| 기본 작업 전부 | 주력 모델(Sol 계열) · **medium** |
| 계획·설계 판단·막힌 버그·최종 검토 | high (그 일이 끝나면 medium으로) |
| 파일 위치 찾기·요약 초안 | 가벼운 모델(Luna 계열) low — 결과는 주력이 다시 확인 |
| 쓰지 않는 것 | 운영 안내가 금지한 모델(10/31 안내: Astra 금지) · Codex 업데이트 · `/fast`(비용이 몇 배) · ultra·xhigh 상시 사용 |
- 바꾸는 법: `/model`에서 모델과 강도를 고른다. 지금 설정은 `/status`로 본다.
- 정보가 부족한 문제는 강도를 올려도 풀리지 않는다. 담당자에게 묻는다.

## 승인 창
- 명령을 읽고 승인한다. 같은 종류(테스트 실행·`git status` 등)가 반복되면 "이 명령은 다시 묻지 않기" 쪽을 한 번 고른다 — **연결이 끊긴 동안 승인 대기로 멈추지 않게.**
- 샌드박스·승인 우회 옵션(`--yolo` 등)은 쓰지 않는다. 키트 설정을 `~/.codex`에 복사하지 않는다(작업 폴더가 홈이면 플랫폼 설정과 섞인다).

## 큰 일 맡기기 — 6칸 지시 (연결이 불안정할 때 특히)
연결된 순간에 끝 조건까지 담아 한 번에 맡기고, 끊긴 동안 다음 지시를 생각한다.
```
[목표] 무엇을 왜 (요건 R번호)
[맥락] 읽을 파일 경로 (붙여 넣지 말고 경로로)
[할 일] 이번에 할 단계 하나
[규칙] 바꾸면 안 되는 것 · 쓰지 말 것
[보고] 바뀐 파일 + 검사 출력 3줄
[끝] "이 검사가 통과하면 커밋하고 멈춰" 같은 끝 조건
```
- 해석이 둘이면 첫 줄에 질문으로 돌려 달라고 쓴다.
- 지시 끝에 "그다음 멈춰"를 붙인다. Codex는 덜 묻고 오래 혼자 달린다.

## 끊김·재접속
- 연결이 끊겨도 원격 환경의 Codex는 계속 돈다는 후기가 많다. 다시 연결되면 화면을 새로고침한다. 중복 접속으로 한 번 더 튕길 수 있다.
- 재접속 뒤 첫 말: `KIT-INDEX.md 읽고 이어서.` → AI는 AGENTS.md 진행 줄부터 읽는다.
- 세션이 꺼졌으면 `codex resume`으로 이전 세션을 고르거나, 새 세션에서 위 첫 말.
- `/tmp/kit`이 사라졌으면 키트를 다시 받는다(`README.md`의 받기 줄). 진행 상태는 과제 폴더의 AGENTS.md·DECISIONS.md에 있다.

## 대화가 길어질 때
- 컨텍스트가 60%쯤 차거나 앞 결정을 잊기 시작하면: "AGENTS.md 진행 줄과 DECISIONS.md를 최신으로 고쳐" → `/new` → `KIT-INDEX.md 읽고 이어서.`
- 자동 요약(`/compact`)을 반복하지 않는다. 요약 중에 결정 이유가 빠진다.

## 탭 나누기
- **파일을 고치는 Codex는 한 탭만.** 두 탭이 같은 파일을 고치면 꼬인다.
- 두 번째 탭은 읽기 전용 검토·공부용: "코드를 고치지 마. 요구 대비 빠진 것·틀린 것·위험을 파일:줄로 표로." 보고를 보고 고칠 것은 사람이 고른다.
- 서버는 Codex 탭이 아닌 별도 터미널 탭에서 띄운다(Codex가 멈춘다).
- 서브에이전트·병렬 작업은 쓰기 담당을 하나로 두고, 나머지는 읽기만 맡긴다. 결과는 메인이 다시 실행해 확인한다. 기능을 많이 늘릴수록 확인 문제가 어려워진다.

## 조작
- 중단 Esc · 종료 Ctrl+C · 입력창 줄바꿈 Ctrl+J 또는 Alt+Enter · 터미널 붙여넣기 Ctrl+Shift+V
- 답이 일본어로 나오거나 일본어 파일명을 만들면 바로 거절하고 "앞으로 답은 한국어, 파일·폴더 이름은 영어 소문자"라고 한 번 말한다(AGENTS.md에도 있다).
- 승인 창은 뜻을 읽고 누른다. 모르는 명령은 "이 명령이 뭘 하는지 한 줄로"를 먼저 묻는다.

## 토큰 (비용도 본다 · 잘하는 사람이 적게 쓴다)
- 한 번에 한 단계. "다 만들어 줘"로 시작하지 않는다.
- 오류는 마지막 20줄만 준다. "전체 다시 봐줘" 대신 파일·함수 이름을 짚는다.
- 보고는 "바뀐 파일 + 검사 3줄"로 받는다. 실행 중에는 같은 요청을 다시 보내지 않는다.
- 담당자 답은 2~3개씩 모아 한 번에 넘긴다. 고칠 것도 모아서 한 번에.
- 같은 오류가 세 번이면 고치기 전에 "원인 후보 2~3개와 확인 방법부터".
