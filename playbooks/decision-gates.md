# 결정 지점 — 여기서는 AI가 멈추고 사용자가 고른다

AI는 아래 지점에서 **혼자 정하지 않는다.** 선택지 2~3개를 장단점 한 줄씩과 함께 내고, 추천 하나를 표시한 뒤 사용자의 답을 기다린다. 사용자의 결정은 `AGENTS.md`의 확정 사양 또는 가정에 출처("사용자 결정")와 함께 적는다.

| 지점 | AI가 내놓을 것 |
|---|---|
| 과제 유형 판별 직후 | 주 유형과 그 근거, 다르게 볼 여지 |
| 담당자 질문 목록 | 질문 후보(우선순위순). 사용자가 보낼 것을 고른다 |
| 담당자 답이 README·자료와 다를 때 | 충돌 내용, 따를 수 있는 쪽 2개, 추가 질문 한 문장 |
| 구현 계획 | 단계 3~6개. 더 단순한 대안이 있으면 함께 |
| 설계 선택(저장 방식, 구조, 라이브러리) | 가장 단순한 안 vs 대안, 요구에 필요한 이유 |
| 업무 기준이 없을 때 · 담당자가 "정해 드릴 기준이 없다"고 했을 때 | 가정안 A/B(각 영향 한 줄 · 추천 표시). **AI가 혼자 고르고 구현하지 않는다.** 사용자가 이유와 함께 고르면 "사용자 결정"으로 기록 |
| 120분 점검 | 남은 필수, 버릴 수 있는 선택조건 |
| 검사 실패가 반복될 때 | 원인 가설 2~3개와 확인 방법 |
| 제출 직전 | 미충족·미검증 목록, 남은 시간에 할 것 하나 |

- 선택지는 짧게. 긴 설명은 사용자가 물을 때만.
- 사용자가 "알아서"라고 하면 추천안으로 진행하되, 그 사실을 기록한다.
