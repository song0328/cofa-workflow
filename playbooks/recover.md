# 막혔을 때 복구

| 증상 | 할 일 |
|---|---|
| AI가 잘못된 방향으로 길게 실행 중 | Ctrl+C로 중단 → "멈춰. 지금까지 바뀐 파일만 보여줘" |
| 코드를 망쳤다 | `git status` → `git diff <파일>` → 마지막 커밋으로: `git restore <파일>` |
| 같은 오류를 계속 못 고친다 | 실패 문구 전체를 주고 "원인 가설 3개와 각각 확인할 명령만. 수정 금지" → 가설 확인 후 하나만 고치게 |
| AI가 사양을 잊었다 | "AGENTS.md를 다시 읽고 요건표 상태만 보여줘" |
| AI가 담당자 답이 없다고 우긴다 | "AGENTS.md 확정 사양 n번은 내가 담당자에게 직접 받은 답이야" |
| 요구하지 않은 기능이 생겼다 | "AGENTS.md 금지 칸 위반. 그 기능만 제거하고 검사 다시" |
| 검사 명령을 모르겠다 | "README와 package.json·테스트 파일에서 검사 명령만 찾아줘" |
| 응답이 너무 느리다 | 요청을 더 작게 쪼갠다. 필요하면 허용 모델 중 다른 모델로 |
| 대화가 너무 길어졌다 | 새 대화 → "AGENTS.md를 읽고 요건표 상태와 다음 단계만" |
| 시간이 부족하다 | `prompts/3-step.md`의 120분 점검 → 선택조건 버림 → `prompts/4-check.md` |
