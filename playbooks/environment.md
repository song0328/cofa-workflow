# 웹 IDE 환경 메모 (사전 체험에서 관찰, 실제 시험에서 다를 수 있음)

| 항목 | 관찰 |
|---|---|
| 작업 경로 | `/home/user` (`~`) |
| 파이썬 | `python` 없음, **`python3`** 사용 |
| Node / git | Node 22 계열, git 2.39 계열 |
| 메모리 | 약 1.6GB 표시 — 서버·프로세스를 여러 개 띄우지 않는다 |
| 홈 git | 홈이 git 저장소이고 환경 파일이 미추적으로 보일 수 있음 |
| 공개 저장소 clone | 됨(승인 필요할 수 있음). 비공개·없는 저장소는 실패 |

## 서버와 미리보기
- 서버는 반드시 **`0.0.0.0:<포트>`** 로 띄운다 (`python3 -m http.server 3000 --bind 0.0.0.0`).
- 첫 실행에 `PermissionError: Operation not permitted`가 날 수 있다 → AI의 **권한 승인 요청을 읽고 승인**한 뒤 다시.
- 서버를 띄운 터미널 탭은 닫지 않는다. 다른 명령은 터미널 `+` 새 탭에서.
- IDE의 Browser에 포트를 넣고 새로고침. 흰 화면이면 브라우저 콘솔 오류·정적 파일 경로·포트를 확인.

## 터미널
- 붙여넣기 **Ctrl+Shift+V**. 붙여넣은 내용이 정확히 들어갔는지 확인 후 전송.
- 선택 영역 없이 Ctrl+C = 실행 중단.
- 디렉터리는 `cd`, 파일은 `cat`으로 읽는다 (`cd README.md` 안 됨).

## AI 상태
- **승인 대기**는 기다려도 진행되지 않는다. 승인 또는 거절.
- 실행 중에 같은 요청을 다시 보내지 않는다.
- 모델이 매우 느리거나 용량 오류면 허용 모델 중 다른 것으로 바꾼다.
