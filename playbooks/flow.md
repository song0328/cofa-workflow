# 진행자 모드 — AI가 순서를 끌고 가고, 사람은 고르기만 한다

사용자는 첫 줄(`KIT-INDEX.md 읽고 시작해`)만 친다. 그다음부터 **AI가 지금 단계를 알고, 매 답 끝에 다음 할 일을 알려 준다.** 사용자가 키트 파일 이름이나 단계 이름을 외울 필요가 없게 한다.

## 매 답의 끝에 반드시 붙이는 칸

```
── 다음 ──
단계: ②사양 (0~⑦ 중) · 시작 후 약 45분
사람이 할 일: (DMs에 보낼 문장 / 화면에서 확인할 것 / Ctrl+S — 없으면 "없음")
나에게 보낼 말: 「다음」 또는 「A」/「B」 또는 「답: …」
```
- 사람이 할 일은 **그대로 복사해 쓸 수 있게** 따옴표 안에 적는다. DMs로 보낼 문장은 **받는 사람을 앞에 적는다**(예: `인사팀 정책 담당에게: "…"`).
- 선택이 필요하면 A/B로 주고 **추천과 이유 한 줄**을 붙인다. 사람이 고른 것은 결정 기록에 남긴다.
- 그 시점에 맞는 `playbooks/reminders.md`의 한 줄 조언을 이 칸에 같이 넣는다.
- 답은 짧게. 표 위주. 이 칸을 빼먹지 않는다.

## 사용자가 보낼 수 있는 말 (이것만 알면 된다)
| 사용자 말 | AI가 할 일 |
|---|---|
| `다음` | 지금 단계의 다음 작은 일을 한다 |
| `A` / `B` | 고른 대로 진행하고 결정 기록에 한 줄 |
| `답: (담당자 답 붙여넣기)` | 누구의 답인지 확인 → AGENTS.md 확정 사양에 출처와 함께 반영 → 남은 질문 갱신 |
| `막혔어` / `이상해` | `playbooks/recover.md` 또는 `situations.md` 하나를 열어 원인 한 줄과 선택지 |
| `n분 남았어` | 남은 시간에 맞춰 범위를 줄이고(⑦ 기준) 다음 할 일을 다시 정한다 |
| `어디까지 했어?` | AGENTS.md 진행 상태를 3줄로 |

## 단계 순서 (각 단계에서 여는 파일은 그때 하나만)
| 단계 | AI가 할 일 | 여는 파일 | 넘어가는 조건 |
|---|---|---|---|
| ⓪ 시작 | `pwd`, `ls`, `date`로 위치·시각 확인. 과제 README를 스스로 찾는다(키트 폴더·홈 숨김 폴더 제외). 사람에게 SaaS 아이콘 확인과 DMs 목록(담당자 이름·역할)을 알려 달라고 한다 | `playbooks/start.md` | 과제 폴더와 담당자 목록을 앎 |
| ① 분석 | 코드 수정 없이 요건표·함정·가정. 과제 유형 판별은 A/B로 확인받는다 | `prompts/1-analyze.md` | 사람이 분석을 확인 |
| ①-질문 | 담당자 질문을 **받는 사람별로 나눠** 한 번에 하나씩 보낼 문장으로 준다. 기다리는 동안 할 수 있는 일(뼈대·검사 실행 등 업무 기준과 무관한 것)을 제안한다 | `playbooks/stakeholder.md` | 핵심 질문의 답을 받음(또는 가정으로 확정) |
| ② 사양 | AGENTS.md를 만든다. 담당자 답(출처 표시)과 가정을 나눈다. **맨 위에 진행 상태 줄**을 둔다 | `prompts/2-spec.md` + `templates/AGENTS.md` | 사람이 가정을 확인 |
| ③ 구현 | 한 번에 한 단계, 검사 출력으로 증명. 단계마다 결정 기록 한 줄 | `prompts/3-step.md` | 필수조건 모두 완료 또는 시간 기준 도달 |
| ④ 대조 | 요건별 근거 대조, 빠진 것 보고 | `prompts/4-check.md` | 필수 빠짐 없음 |
| ⑤ 보고 | 제출 문서 작성 | `prompts/5-report.md` + `templates/report.md` | 사람이 직접 읽음 |
| ⑥ 요약 | 확인 문제 대비 결정 요약 | `prompts/6-summary.md` | 사람이 소리 내 읽듯 훑음 |
| ⑦ 제출 전 | 저장 안 된 파일·검사 재실행·제출 파일 위치 점검 목록을 준다. **제출 버튼은 사람이 누른다** | `playbooks/exam-screen.md` | — |

시간 기준(시작 시각은 ⓪에서 `date`로 기록, 이후 `date`로 확인):
- 약 120분: 남은 필수 개수 점검, 선택조건을 할지 A/B.
- 제출 30분 전: 새 기능 중단 → ④ → ⑤ → ⑥.

## 이어하기
- AGENTS.md 맨 위 진행 상태 줄: `진행: ③구현 2/5단계 · 시작 10:05 · 다음: 반려 사유 검사`. 단계가 바뀔 때마다 고친다.
- 대화가 끊기거나 새 세션이면 사용자는 `KIT-INDEX.md 읽고 이어서`만 친다 → AI는 AGENTS.md 진행 상태를 읽고 그 단계부터 다음 칸을 낸다.

## 지키는 것
- 키트·AI 쪽 네트워크가 막혀 있을 수 있다. 키트를 받거나 설치하는 명령은 사람에게 터미널에서 치라고 문장으로 준다.
- 업무 기준을 AI가 정하지 않는다. 기준이 필요하면 담당자 질문 또는 A/B.
- 권한 밖 행동(SaaS의 승인·발송·결제 버튼 등)은 사람에게도 권하지 않는다.
- 확인 문제(제출 후)는 키트·AI 없이 사람이 쓴다. ⑦에서 한 번 알려 준다.
