# ⑤ 보고 — 제출 문서를 채운다

1. **제출 파일 이름은 README의 제출물 안내에서 확인**한다. 사용자가 이름을 주면 그 파일만 쓴다. README 자체를 고치지 않는다.
2. 틀은 `templates/report.md`. 짧게, 사실대로:
   - 확인한 것(담당자 확인 사실) / 내 가정
   - AI에 맡긴 것 / 사용자가 직접 검증한 입력과 결과
   - 뺀 기능과 이유 / 남은 위험·미검증
3. **확정한 값만** 쓴다. 문장마다 근거(README 줄·담당자 답·검사 출력)를 괄호로 붙이고, 보고서를 쓰면서 새 계산·새 가정을 더하지 않는다. 판단할 정보가 없으면 추측하지 말고 "정보 없음(확인 필요)"으로 적는다. 원자료에 없는 원인을 쓰면 "추정"이라고 표시한다.
4. 쓴 뒤 필요한 전체 검사를 다시 실행하고 결과를 보여 준다. 실행하지 않은 검사·사람이 보지 않은 화면을 확인했다고 쓰지 않는다.
