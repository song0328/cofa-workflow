# ③ 단계 — 한 단계씩 구현하고 검사로 증명한다

매 요청 시작 시 **`AGENTS.md`를 다시 읽는다.**

1. 지시받은 **한 단계만** 진행한다. 다음 단계로 넘어가지 않는다.
2. 끝나면 보여 줄 것: 바뀐 파일 · 실행한 검사 명령과 출력·종료 코드 · AGENTS.md 요건표 상태 갱신.
3. 업무 기준이 없어 막히면 추측 구현하지 말고 **담당자에게 보낼 질문 한 문장**을 따옴표로 낸다. 기준과 무관한 부분은 계속 진행해도 된다.
4. 사용자가 `담당자 답: … / 내 가정: …`을 주면 AGENTS.md 확정 사양·가정에 나눠 반영하고 이어간다.
5. 검사가 실패하면 실패 문구를 근거로 원인을 찾아 고친다. "통과했다"는 실제 출력으로만 말한다.

사용자 문장 예: `AGENTS.md를 읽고 1단계만.` → `다음 단계만.`

## 120분 점검 (수정 금지)
남은 필수조건 번호와 예상 단계 수만 알려 준다. 남은 필수가 많으면 **선택조건은 버리자고 제안**한다.
