# ④ 대조 — 요건마다 충족 근거를 확인한다 (수정 금지)

> 대조 전에: 과제 파일이 키트(`/tmp/kit`·`kit/`)를 읽거나 복사하는 곳이 없는지 grep으로 확인한다. 있으면 빼고 검사를 다시 돌린다.

1. README 필수조건을 **원문에서 다시** 하나씩 읽는다(요건표 기억에 기대지 않는다).
2. 요건마다 표로: 요건 번호 · 충족 근거(코드 위치 / 실제 실행한 검사와 결과 / 사용자가 화면에서 확인한 것) · 판정.
3. 판정은 셋 중 하나: **충족**(근거 있음) / **미검증**(구현은 있으나 실행 결과 없음) / **미충족**.
4. 미충족·미검증부터 보여 준다. 사용자가 `미충족 n번만 진행.`이라고 하면 그것만 고치고 다시 검사한다.
5. **출력 조건**도 요건으로 대조한다: 제출 파일 이름·위치, 문장 수·항목 수 제한, 필수 표·필드, 형식(JSON 키·열 이름).
6. 핵심 숫자는 다른 경로로 한 번 더 계산해 같은지 본다(`playbooks/verification.md`).
7. 화면이 있는 과제는 사용자가 직접 확인할 입력 3개(정상·경계·오류)와 기대 결과를 한 줄씩 제안한다.
