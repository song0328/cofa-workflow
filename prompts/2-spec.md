# ② 사양 — 확정 사실로 AGENTS.md를 만들고 계획만 세운다

사용자가 담당자에게 확인한 사실(대화 전문 또는 요약)을 준다. **사용자가 직접 확인한 사실로 취급한다.** 코드 수정 금지.

1. `templates/AGENTS.md` 틀로 과제 폴더에 `AGENTS.md`를 만든다. 다섯 칸:
   - **요건표** — 번호·필수/선택·근거·상태(미착수/진행/완료/미검증)
   - **확정 사양** — 담당자 답과 README에 있는 것만, 출처와 함께 짧게
   - **가정** — 담당자가 답하지 않았거나 "정할 기준이 없다"고 한 것
   - **금지** — README·담당자 답에 없는 기능·오류 코드·필드 추가 금지 / README·원자료·플랫폼 설정 수정 금지 / 화면 조작·확인은 사용자가 한다 / 실제 발송·결제 등 외부 동작 금지
   - **규칙** — 완료라고 말하기 전에 검사 명령을 실행하고 출력·종료 코드로 증명 / 업무 기준이 없으면 추측하지 말고 멈춰서 담당자 질문 한 문장 / 검사 통과한 단계마다 과제 파일만 커밋
2. **필수조건부터** 3~6단계 계획을 보여 준다. 각 단계에 "무엇으로 확인하나"를 붙인다. 문서만 쓰는 단계는 만들지 않는다.
3. 계획과 설계 선택은 결정 지점이다 — 더 단순한 대안이 있으면 함께 내고 사용자가 고르게 한다(`playbooks/decision-gates.md`).
4. 계획이 과하면(선택조건·추가 기능·범용 설계) 스스로 줄인다. `playbooks/scope.md`.
