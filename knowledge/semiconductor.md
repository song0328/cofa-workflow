# 반도체 자료 — 수율·검사·결함·설비 시계열

원칙: 과제가 이런 자료를 줄 때만 연다. "반도체 회사니까 수율 예측"이라 추정하지 않는다. 계산 전에 **한 행의 뜻·키·검사 단계·단위·분자/분모·재검사 정책**을 문장으로 적는다. 아래 기본값보다 데이터 사전·담당자 답이 우선.

## 담당자에게 물을 것 (하나씩)
- "수율은 최초 검사 통과 기준인가요, 재검사 후 최종 판정 기준인가요?"
- "같은 die가 재검사로 여러 행이면 어느 결과를 인정하나요?" (첫 / 마지막 / 승인된 판정)
- "defects 열은 결함 건수인가요, 불량 die 수인가요?"
- "수율은 전체 합산(통과 합/검사 합)인가요, wafer별 비율의 평균인가요?"
- "분모에 미검사·중단·edge die를 넣나요?"
- "wafer ID는 lot 안에서만 유일한가요?"
- "관리한계는 어느 기간 자료로 정하나요? 규격(LSL/USL)이 따로 있나요?"

## 흔한 함정
| 함정 | 막는 법 |
|---|---|
| defects를 불량 개체 수로 보고 `1 - defects/tested`를 수율로 | defects는 결함 **건수**일 수 있다(한 die에 여러 건). 불량 die 비율 = 불량 die/검사 die, 결함 밀도 = 결함 건수/검사 개체. 셋은 다른 지표 |
| 행별 비율 평균을 수율로 | 기본은 `sum(passed)/sum(tested)`. 평균이 요구일 때만 평균 |
| wafer·die·package 단위 섞기 | 지표마다 단위를 적고, 단위가 다른 표끼리 더하지 않는다 |
| 재검사 행을 그냥 지우거나 다 더함 | 어느 결과를 인정할지 묻는다. 최초·최종·전체 시도는 서로 다른 숫자 |
| 조인 뒤 행이 불어남 | wafer 집계 1행 × 결함 3행 → tested가 3번 더해진다. 결함은 원하는 단위로 먼저 집계한 뒤 결합 |
| `wafer_id`를 전역 유일로 | 키는 (lot, wafer). ID는 문자열로 읽어 앞자리 0 보존 |
| tested=0·결측을 0%로 | "산출 불가"로 따로 표시 |
| 파일 행 순서 = 시간순 | 시각·순번으로 정렬, 같은 시각 정책을 정한다 |
| 관리한계 이탈 = 불량·원인 확정 | 이탈은 **조사할 신호**. 규격 불합격과 다르다 |
| 규격 없이 Cpk | LSL/USL이 없으면 Cpk를 계산하지 않는다. 평균±3σ를 규격처럼 쓰지 않는다 |
| 감시 구간까지 넣어 한계 재계산 | 기준 기간을 먼저 고정, 감시값은 판정에만 |
| Pareto 1위·상관을 근본 원인으로 | "관찰 → 가능한 설명 → 추가 확인"으로 쓴다 |

## 구현 요령
- 지표 문장부터 쓴다: "제품 X·최종 검사·10월, 최종 판정이 있는 서로 다른 die 중 통과 비율". 그다음 열을 매핑한다.
- 재검사: 원본은 두고, 정책(최초/최종)을 적용한 분석 표를 새로 만든다. 고른·뺀 시도 수를 기록한다.
- 조인: 전에는 양쪽 키 유일성, 후에는 행 수·고유 개체 수·분자/분모 합계를 대조한다.
```python
def pass_rate(rows):                    # 합산 통과율, 분모 0이면 산출 불가
    t = sum(r["tested"] for r in rows); p = sum(r["passed"] for r in rows)
    return None if t == 0 else p / t
def imr_limits(base):                   # 기준 기간 값(시간순) → 한계, 감시값은 넣지 않는다
    mr = [abs(b - a) for a, b in zip(base, base[1:])]
    mrbar = sum(mr) / len(mr); sigma = mrbar / 1.128; c = sum(base) / len(base)
    return {"center": c, "lcl": c - 3*sigma, "ucl": c + 3*sigma, "mr_ucl": 3.267 * mrbar}
```
- I-MR은 한 장비·챔버·recipe·측정 항목의 시간순 연속값 하나에만 쓴다(비율·건수에는 쓰지 않는다). 정비·recipe 변경 전후는 나눈다. 긴 결측을 건너 MR을 이을지 정한다. MRbar=0이면 "변동 추정 불가"(정상 확정 아님).
- 3σ 이탈 규칙만 썼으면 "추세·연속 규칙은 미적용"이라 쓴다.
- 예측이 필요할 때만 `playbooks/types/prediction.md`(lot·wafer 그룹 분할, 예측 시점 특징).

## 검사 사례
- 합산 대조: W1 9/10 + W2 45/90 → 54/100 = 54%. 행별 평균 70%가 나오면 틀림
- 4 die 중 2개에 결함 5건 → 불량 die 비율 2/4, 결함 밀도 1.25건/die. `1-5/4` 같은 음수 수율이 없어야 한다
- 재검사: A 1차 실패→2차 통과, B 통과, C 실패 → 최초 1/3 · 최종 2/3 · 전체 시도 2/4 중 담당자가 정한 하나
- tested=0 → 산출 불가 / passed>tested·음수 수량 → 오류 목록
- 조인 전후 tested 합계가 같다
- I-MR 손계산: 기준 10,11,10,11 → 중심 10.5, MRbar 1, I 한계 약 7.84~13.16, MR 상한 3.267. 다음 값 15 → I 이탈이면서 MR 4로 MR 이탈
- 감시값을 추가해도 한계가 바뀌지 않는다
