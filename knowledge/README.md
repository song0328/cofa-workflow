# knowledge — 주제별 지식 (필요한 것만 1~2개)

과제 README에 아래 주제가 나오면 **해당 파일만** 연다. 전부 읽지 않는다. 각 파일은 같은 순서다: **담당자에게 물을 것 → 흔한 함정 → 구현 요령 → 검사 사례.**

이 문서들은 일반 지식이다. **과제 README·제공 파일·담당자 답이 언제나 우선**한다. 여기 있는 기본값을 업무 규칙처럼 쓰지 않는다 — 기본값이 필요하면 가정으로 적고 사용자에게 A/B로 확인받는다.

|---|---|
| 로그인·권한·역할·관리자·개인정보·비밀번호·"보안"·외부 입력 | `security.md` |
| 승인·반려·결재·상태(대기/완료/취소)·담당자 배정·권한별 처리 | `workflow-permissions.md` |
| 날짜·기간·마감·영업일·휴일·근무시간·SLA·시간대·"몇 일/몇 시간" | `dates-time.md` |
| 금액·가격·정산·환불·할인·세금·수수료·반올림·대사 | `money.md` |
| CSV·엑셀·로그·중복·정정·취소 기록·집계·통계·보고서 숫자 | `data-quality.md` |
| 예약·재고·좌석·쿠폰·한정 수량·중복 요청·동시 요청 | `booking-inventory.md` |
| API·엔드포인트·상태 코드·오류 응답·목록 조회·검색·정렬·페이지 | `api-design.md` |
