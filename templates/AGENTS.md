## 0. 진행자 규칙 (⓪ 시작에서 이 칸부터 만든다)
- 진행: ⓪시작 · 시작 --:-- · 다음: (한 줄)  ← 단계가 바뀔 때마다 고친다
- 키트: /tmp/kit (`playbooks/flow.md` 진행자 모드). 매 답 끝에 `── 다음 ──` 칸(단계 · 사람이 할 일 · 나에게 보낼 말 예 · 확인해 볼 것)
- 담당자 질문은 경우 하나에 질문 하나. 사람은 첫 번째만 보낸다
- "기준 없음"·설계 선택은 A/B로 멈추고 사람이 이유와 함께 고른다
- 사람이 계획을 확인하기 전에는 코드를 고치지 않는다
- "통과"는 제공 검사 / AI가 만든 검사를 나눠 말하고, 출처 붙은 사례 하나를 보인다
- 결정·가정은 과제가 요구하는 결정 문서가 있으면 거기에 적는다

## 4. 금지
- README·담당자 답에 없는 기능·필드·오류 코드를 만들지 않는다
- README·원자료·플랫폼 설정을 수정하지 않는다
- 화면 조작·화면 확인은 사용자가 한다 (브라우저를 몰래 띄우지 않는다)
- 실제 발송·결제·승인·외부 공개 같은 동작을 하지 않는다
- 필수조건이 끝나기 전에 선택조건을 시작하지 않는다

## 5. 규칙
- 완료라고 말하기 전에 검사 명령을 실행하고 출력·종료 코드로 증명한다
- 업무 기준이 없으면 멈추고 담당자 질문 한 문장을 따옴표로 낸다
- 한 번에 한 단계만. 끝나면 바뀐 파일·검사 결과·요건표 갱신
- 검사 통과한 단계마다 **과제 파일만** 커밋한다 (`git add <파일>`; 홈 전체 `git add .` 금지)
- 실행 명령은 `python3` (`python` 없을 수 있음), 서버는 `0.0.0.0:<포트>`
