# ①-질문 담당자에게 묻기 (10~40분 · 기다리는 동안 다른 일 진행)

## 규칙 (전부 지킨다)
- **한 메시지 = 물음표 하나.** 경우를 나열해도 묶음이다. AI는 우선순위 목록을 내고 사람은 **맨 위 하나만** 보낸다.
- 받는 사람을 앞에 쓴다: `인사팀 정책 담당에게: "…?"`. 업무 규칙은 업무 담당자에게, 화면 사용법은 Helper에게.
- 근거를 붙인다: `"[파일]의 [열]에 [값]이 n건 있는데, ○○로 봐도 될까요, △△로 봐야 할까요?"`
- 파일에 답이 있는 것은 묻지 않는다. "할 일을 1·2·3으로 알려 달라"는 금지.
- 순서: 지금 방식·불편 → 넘으면 안 되는 한계(숫자) → 이용자가 포기하는 선 → 무엇이 먼저인가 → 예외 대상 → 사용 빈도 → 역할·볼 수 있는 것 → 동시 수정·실패 시.
- 입력은 1000자 제한: 긴 답은 핵심 1~3문장으로, 그래도 길면 `답(1/2)`·`답(2/2)`로 나눠 받는다(다 오기 전엔 "받음"만).
- 답이 오면 **즉시** AGENTS.md 「2-1. 받은 자료」에 원문·출처·시각. "기준 없음"이면 「3. 가정」에 `기준 없음(시각)`, 다시 묻지 않는다.
- 돌려 말하면: 닫힌 질문("10인가요, 20인가요?") → 확인 질문("○○로 이해했는데 맞나요?") → "○○로 가정하고 진행할게요" 선언. 왕복 12번쯤 넘으면 남은 것은 가정.
- 기다리는 동안: 뼈대·진단·검사 실행처럼 업무 기준과 무관한 것만. 탐구 탭(예외 사냥·질문 초안)을 따로 돌려도 된다(`playbooks/parallel.md`).
