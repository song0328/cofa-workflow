# ① 분석 (5~25분) — 코드 수정 없음

## 할 일
1. README로 **첫 10분 표**: 결정할 것 / 반드시 지킬 조건 / 점수로 조정할 것 / 자원 상한(개수·용량·시간) / 평가 지표 / 데이터 규모 / 제출물 목록. 빈칸 = 담당자 질문.
2. 요건표(R번호·근거 줄. README가 필수/선택을 표시했을 때만 구분, 없으면 전부 필수)를 AGENTS.md 「1」에.
3. **자료가 있으면 진단 1회**: `python3 <키트>/tools/data_profile.py <자료 폴더>` (변경본·오류 검증용 자료가 있으면 `--compare 원본 변경본 --key 열1,열2`). 파일마다 `head -5`로 실제 값을 보고 README 단어와 대조.
4. **예외 후보 표**: 후보 / 근거(파일·열·건수) / 결과에 주는 영향 / 담당자 질문 / 답 전 처리(보류). 영향 큰 순서.
5. 과제 유형을 A/B로 확인받는다.

## 조건이 맞으면 더 읽기 (절만: `python3 <키트>/tools/kit_read.py <파일> "<절>"`)
| 조건 | 읽을 것 |
|---|---|
| 자료 예외를 더 찾아야 | `playbooks/edge-hunt.md` "사람 눈으로 볼 8가지" |
| 계산·배정·경로·일정·"최적" | `playbooks/types/optimization.md` "먼저 볼 것" |
| 로그인·역할·관리자 | `knowledge/security.md` "담당자에게 물을 것" |
| 다른 주제(날짜·금액·예약 등) | `knowledge/README.md` 표에서 1개 → 그 파일 "담당자에게 물을 것"·"흔한 함정" |
| 기존 코드 수정·데이터 보고 등 유형 | `playbooks/task-types.md` → 유형 파일 하나 |

## 놓치면 안 되는 것
- [ ] 자원 상한(개수·용량·시간)이 README에 없으면 그것이 첫 질문 후보
- [ ] "다만·단·제외" 단서 조항, 언어별 README 차이
- [ ] 기본값을 업무 규칙처럼 정하지 않는다(질문이나 가정으로)
