# ⑦ 제출 (제출 시작 시각 = 종료 −50분 · 과제 타이머가 먼저 끝나면 그 −10분)

## 순서
1. **제출물 정리**: AGENTS.md 「8. 제출물 목록」과 실제 파일 대조. 실험·임시 파일·worktree·키트 흔적 제거. `git status -s`, `ls -a`. 과제 파일에 키트 참조가 없는지 `grep -rn "kit" --include=*.py --include=*.js --include=*.cjs .`
2. 과제가 정한 검사 명령(README·package.json·처음 받은 test 파일)을 찾아 **사람이 터미널에서 직접** 실행하게 한 줄로 준다. 실패면 제출하지 않고 그 오류만 고친다.
3. 사람: Ctrl+S 저장 확인 → 제출 문서 직접 읽기 → `노트 보여 줘` 두 번.
4. `제출하고 문제풀기` → 미리보기(일부만 보이고 숨김 폴더는 빠질 수 있다) → `제출물 확정하고 문제풀기` → 질문 생성 대기 5~10분 동안 「외울 것」 떠올리기.
5. **제출 버튼은 사람이 누른다.** 확인 문제가 시작되면 AI·키트는 쓰지 않는다.

## 사용자에게 건넬 말
"확인 문제는 이름표(방식/이유/대안/포기/확인)부터 치고 채우세요. 결정→약점→파급→다음 검증. 실제 숫자 하나. 시간이 끝나면 자동 확정됩니다."
