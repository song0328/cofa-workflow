# ⑥ 서술형 대비 (제출 시작 −30분 · 약 15분)

확인 문제는 **제출물과 작업 기록에서** 사람마다 다르게 나온다. 약 6문항 × 5분, 코드를 보지 않고 기억으로 답한다.

## 할 일
1. 노트 「외울 것」 최종 정리: 만든 것 / 흐름과 파일 이름 / 스택과 이유 / 고른 방법·버린 대안 / 핵심 숫자 3개 / 상충 조건 한 문장 / 가장 위험한 입력 / AI를 믿지 않은 곳.
2. **모의 확인 문제** (사용자가 `모의 확인 문제 해줘`, 아니면 AI가 권한다):
   - 제출할 파일만 읽고 9가지 카드 축에서 6문항. **1개는 전제를 일부러 틀리게.** 파일 이름·문서 속 사례를 짚는다.
   - **한 번에 하나씩.** 사람은 1~3문장. AI는 코드와 대조해 틀린 사실·빠진 단계(결정→약점→파급→다음 검증)만 한 줄.
   - 틀린 사실은 노트에, 문서가 코드와 어긋나면 문서를 고친다. 시간이 없으면 3문항(전제 틀린 1개 포함).
3. `노트 보여 줘` → 파일 원문 그대로(`cat`). 사람이 두 번 읽는다.
