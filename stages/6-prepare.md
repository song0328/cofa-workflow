# ⑥ 서술형 대비 (제출 시작 −30분 · 약 15분)

확인 문제는 **제출물과 작업 기록에서** 사람마다 다르게 나온다. 약 6문항 × 5분, 코드를 보지 않고 기억으로 답한다.

## 할 일
1. 노트 「외울 것」 최종 정리: 만든 것 / 흐름과 파일 이름 / 스택과 이유 / 고른 방법·버린 대안 / 핵심 숫자 3개 / 상충 조건 한 문장 / 가장 위험한 입력 / AI를 믿지 않은 곳.
2. **모의 확인 문제** (사용자가 `모의 확인 문제 해줘`, 아니면 AI가 권한다):
   - `python3 <키트>/tools/predict_questions.py .` → 예상 6칸(방법·구조·구현 vs 가정·장애·변화·AI 협업)에서 한 문항씩. **1개는 전제를 틀리게.** 「출제 범위 경고」가 있으면 그 파일을 빼거나 설명할 수 있게 한다.
   - **한 번에 하나씩.** 사람은 1~3문장(코드를 보지 않고). AI는 코드와 대조해 0~3점과 표시만: `근거 없는 숫자` · `없는 기능` · `과장` · `막다른 답`(모름으로 끝남) · `장황`(첫 문장에 답 없음) · `증거 없음` · 빠진 단계(결정→약점→파급→다음 검증).
   - 약했던 칸은 **조건을 바꿔 한 번 더**(입력·제약·실패 시점을 바꾼 새 질문). "알겠다"만으로는 통과가 아니다.
   - 틀린 사실은 노트 「말하면 안 되는 미확인 주장」에, 문서가 코드와 어긋나면 문서를 고친다. 시간이 없으면 3문항(전제 틀린 1개 포함).
(문서를 쓰는 동안 탐구 탭에 예상 서술형·문서-코드 불일치 찾기를 맡겨도 된다 — `playbooks/parallel.md`)
3. `노트 보여 줘` → 파일 원문 그대로(`cat`). 사람이 두 번 읽는다.
