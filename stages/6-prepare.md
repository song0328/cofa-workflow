# ⑥ 서술형 대비 (검사·문서를 마친 뒤 · 약 15분)

확인 문제는 **제출 폴더의 파일 전부와 작업 기록에서** 나온다. 약 6문항 × 5분, 코드 없이 기억으로 답한다. 한 주제에 몰려 묻기도 한다.

## 할 일
1. **5분 무힌트 회상**: 사람은 코드·노트 없이 네 문장을 쓴다 — ① 만든 것과 데이터 흐름 ② 가장 중요한 결정·이유·버린 대안 ③ 직접 확인한 숫자와 방법 ④ 가장 큰 한계와 운영 첫 일. AI는 대신 쓰지 않고 틀린 사실만 고친다.
2. **모의 확인 문제**(`모의 확인 문제 해줘`, 아니면 AI가 권한다): `python3 <키트>/tools/predict_questions.py .`의 6칸과 「집중 질문」에서 한 문항씩, 1개는 전제를 틀리게. 구조 칸은 역할 하나의 실제 데이터 흐름, AI 칸은 사람이 재검토시킨 실제 사례.
   - **한 번에 하나씩.** 사람은 1~3문장. AI는 코드와 대조해 0~3점과 표시만: `근거 없는 숫자`·`없는 기능`·`과장`·`막다른 답`·`장황`·`증거 없음`·빠진 단계.
   - 약했던 칸은 조건을 바꿔 한 번 더. 틀린 사실은 노트 「말하면 안 되는 미확인 주장」에, 문서가 코드와 어긋나면 문서를 고친다. 「출제 범위 경고」 파일은 빼거나 설명할 수 있게 한다.
3. **제출 루트 `Answers.md`**: 틀 `templates/Answers.md`, 분량·말투는 `templates/Answers-example.md`대로 핵심 결정 6각도와 번호 붙은 질문·답을 쓴다(`playbooks/followup-prep.md` "Answers.md"). 확인된 사실만, 쉬운 말로. README가 추가 문서를 막으면 요구 문서의 한 절로.
4. 사람이 `Answers.md`를 전부 읽고 고친다 → `답 파일 보여 줘`(원문 `cat`)로 두 번 읽는다.

## 답 틀 (사람에게 한 번 보여 준다)
`python3 <키트>/tools/kit_read.py playbooks/answer-cards.md "모든 답의 뼈대" "5분 쓰는 법" "하지 않는 것"`

사람이 원하면 바로 연습할 말: `역할별 데이터 흐름을 쉬운 말로 연습하자` · `내가 AI를 재검토시킨 사례만 질문해 줘` · `핵심 결정만 각도 바꿔 계속 물어봐`.
(계약이 확정된 뒤 꼭 필요하면 읽기 전용 검증 탭으로 문서-코드 불일치만 점검할 수 있다 — `playbooks/parallel.md`)
