# ③ 구현 (45~150분) — 한 단계씩, 검사로 닫는다

## 단계 하나의 순서 (매 단계 반복)
1. 지시받은 **한 단계만**. 빈 폴더면 `recipes/` 틀을 계약에 맞게 고쳐 쓴다(과제 파일이 키트를 참조하지 않는다).
2. **사람 예측 → 실행**: 핵심 검사·경계 입력 전에 사람의 `예상: …` 한 줄을 받고, 실행 뒤 `예상/실제/차이`를 노트에.
3. 검사로 증명: **제공 검사 / AI 검사**를 나눠 말하고 출처 붙은 기대값 사례 하나. **테스트 정직성**(`playbooks/verification.md` "테스트 정직성"): 새 테스트는 먼저 올바른 이유로 실패하는 것을 본다 · 통과시키려고 약하게 고치지 않는다 · 0개 = 미검증.
4. 예외 하나 = 테스트 하나(이름에 내용). 알고 쓴 지름길에는 `# 한계: 무엇, 언제 바꿀지` 주석.
5. **과제 파일만** 커밋(`git add <파일>`), 메시지에 R번호.
6. AI 제안을 받아들이거나 고치거나 버렸으면 **즉시** `AI_COLLABORATION.md`에 한 행.
7. 이해 체크포인트(3줄 + 질문 1) · 노트 해당 카드만 갱신 → `노트 갱신: 카드 n`.
8. 사람 확인은 **번호로**: `S2-1 누를 것 → 보일 것`(정상·경계·오류). 사람은 `S2-1 실패: …`로 답한다.
